# WildObserve releases

Downloads of WildObserve, a desktop app that turns camera-trap images into reviewed wildlife observations. Your images, their metadata and your annotations never leave your computer.

**To install:** open the newest release below and download the `.dmg` for Mac (Apple Silicon).

## What else is here

- **`latest.json`** in each release tells WildObserve's update check about that version. The app reads it from the newest release; it sends nothing but its own version and operating system.
- **The `licenses` pre-release** holds license files for activation by key. Each is encrypted with its license key and named by it, so it names no one and opens only with the key.

WildObserve is made by Quantitative Science Consulting, LLC. The source code isn't in this repository.
