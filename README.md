# WildObserve™ releases

Downloads for [WildObserve™](https://www.qsc.earth/WildObserve/), free desktop camera-trap software for Mac, Windows, and Linux. AI finds animals, suggests species, and learns from your labels as you review. Your images, their metadata and your annotations never leave your computer.

## Install

- **Mac** (Apple silicon, macOS 14 or later): download [`WildObserve.dmg`](https://github.com/mikeyEcology/wildobserve-releases/releases/latest/download/WildObserve.dmg).
- **Windows** (10 or later): get it from the [Microsoft Store](https://apps.microsoft.com/detail/9nlwg3wvnzbk).
- **Linux** (Ubuntu 22.04 or later, 64-bit Intel or AMD): download [`WildObserve-amd64.deb`](https://github.com/mikeyEcology/wildobserve-releases/releases/latest/download/WildObserve-amd64.deb), then run `sudo apt install ./WildObserve-amd64.deb`.

These links always get the newest version. The [user guide](https://www.qsc.earth/WildObserve/user_guide.html#install) has step-by-step instructions.

The Community plan is free. See [Plans](https://www.qsc.earth/WildObserve/plans.html) for the others.

## What else is here

- **`latest.json`** in each release tells WildObserve's update check about that version. The app reads it from the newest release; it sends nothing but its own version and operating system.
- **`downloads.csv`** counts each day's downloads of the newest release's files. A workflow updates it every hour from GitHub's download totals.
- **The `licenses` pre-release** holds license files for activation by key. Each is encrypted with its license key and named by it, so it names no one and opens only with the key.

WildObserve is made by [Quantitative Science Consulting, LLC](https://www.qsc.earth). The source code isn't in this repository.
